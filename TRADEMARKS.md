# The ToBeBestMe name and icon

The MIT License covers ToBeBestMe's code. It does not cover the name "ToBeBestMe" or its icon (`assets/icon.svg`, `assets/icon.png`).

- You may use, change and share the code, as the license says.
- If you share a changed version, give it a different name and icon, and don't present it as the official ToBeBestMe. Saying it is "based on ToBeBestMe" is fine.
- Copies installed from anywhere other than the official repository may have been altered. ToBeBestMe checks its own files against the release they came from; see SECURITY.md for how to verify a download.

This is a statement of how the ToBeBestMe contributors ask the name and icon to be used. It is not a claim of a registered trademark.
